# MQTT protocol v1 — planned M5 contract

Status: **design only; not implemented**. Namespace: `stemlab/v1/devices/{deviceId}/{status|heartbeat|commands|acks|telemetry}`. Commands require UUID command/session IDs, active server lease, expiry, bounded values and an ACK. QoS, retry, retained state, LWT, TLS client identity and per-device ACL will be integration-tested with a fake device before this status changes.

The Compose broker is internal development infrastructure only and anonymous solely because M5 provisioning does not exist yet. It has no published host port.
