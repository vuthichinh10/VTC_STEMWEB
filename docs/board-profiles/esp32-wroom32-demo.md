# ESP32-WROOM-32 demo profile

> **DEMO PROFILE — VERIFY AGAINST PHYSICAL HARDWARE**

V4 references GPIO 18, 19, 21/SDA, 22/SCL, 23, 25, 26, 27, 32, 33, 34 and 35. GPIO34/35 are input-only and have no internal pull-up/down. Logic is 3.3 V. LEDs require a current-limiting resistor; buzzer and servo need suitable drivers/power, with common ground. This is educational metadata, not a production custom-board pinout.
